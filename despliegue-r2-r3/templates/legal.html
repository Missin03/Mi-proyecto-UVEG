INFORMACIÓN SOBRE TUS DATOS

Aviso de privacidad

Agenda Académica es una aplicación local de práctica administrada por Emmanuel Missin Garcia Vargas. Su finalidad es organizar tareas por materia y fecha de entrega.

Datos y finalidad

Se guardan títulos, descripciones, materias, fechas de entrega, estados y fecha de creación. Se utilizan para mostrar, buscar y actualizar las tareas. Usa datos de prueba y evita incluir información personal sensible.

Protección y conservación

La base de datos está limitada al equipo local. La aplicación valida las entradas, utiliza consultas parametrizadas y protege los formularios contra solicitudes no autorizadas. En el despliegue HTTPS, la conexión se cifra. Una cookie de sesión permite validar los formularios y mostrar avisos; no se usa para publicidad.

Control sobre la información

Los registros se conservan durante la práctica. Puedes solicitar acceso, corrección o eliminación al responsable mediante la mensajería institucional del aula UVEG. No se transfieren registros a terceros ni se integran servicios de analítica externa.

Última actualización: 4 de octubre de 2026.

CONDICIONES DE LA PRÁCTICA

Términos de uso

Agenda Académica permite registrar, consultar y actualizar tareas en un entorno local de aprendizaje. El uso de la aplicación supone conocer estas condiciones.

Uso permitido

Utiliza la aplicación para ejercicios académicos con datos de prueba. No introduzcas contraseñas, documentos de identidad o datos sensibles. No intentes modificar otros sistemas, evadir controles ni cargar contenido ilícito.

Alcance y responsabilidad

La aplicación es una práctica educativa de uso individual. No sustituye el calendario oficial de UVEG ni garantiza recordatorios, disponibilidad continua o conservación indefinida de información. El usuario debe comprobar sus fechas en el portal escolar.

Cambios y atención

El responsable puede actualizar el software durante la práctica. Para reportar errores o solicitar atención sobre registros, utiliza la mensajería institucional del aula UVEG dirigida al responsable.

Última actualización: 4 de octubre de 2026.
